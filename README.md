# Практическая работа №7: Разработка консольной утилиты на Bash

## Описание работы
Данная программа представляет собой консольную утилиту, предназначенную для получения системной информации (список пользователей и запущенных процессов) с гибкой системой управления выводом.

## Функционал
Скрипт поддерживает следующие аргументы командной строки:
* `-u`, `--users` — выводит список всех пользователей и их домашних директорий (отсортировано по алфавиту).
* `-p`, `--processes` — выводит список запущенных процессов (отсортировано по идентификатору PID).
* `-l PATH`, `--log PATH` — перенаправляет стандартный вывод в файл по указанному пути.
* `-e PATH`, `--errors PATH` — перенаправляет поток ошибок (stderr) в файл по указанному пути.
* `-h`, `--help` — выводит справку по использованию программы.

## Как запустить
1. Сделайте файл исполняемым:
   ```bash
   chmod +x sysinfo.sh

2. Запустите скрипт с нужными параметрами:

 ```bash
- ./sysinfo.sh -u             -  Вывод пользователей в консоль
- ./sysinfo.sh -p -l log.txt  -  Вывод процессов в файл log.txt
- ./sysinfo.sh -h             -  Справка
```


# Особенности реализации

Использован механизм getopt для корректной обработки длинных и коротких аргументов.
Реализована проверка прав доступа к путям файлов при перенаправлении вывода.
Логика каждой команды вынесена в отдельные функции.
